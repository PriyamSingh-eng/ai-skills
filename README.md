# Codex skills

A collection of reusable Codex skills.

## Included skills

- `skills/github-pr-review`: evidence-based, stack-aware GitHub pull request review with optional Jira context and approval-gated review submission.

## Local configuration

Copy `skills/github-pr-review/.env.example` to `skills/github-pr-review/.env` and fill in credentials locally. Never commit `.env` or real tokens.
